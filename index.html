Orthogonal Transformation Lab

2D / 3D 벡터·곡선·평면을 행렬로 변환하고, 직교행렬의 성질을 실험하는 도구

1. 변환 대상

범위는 -2..2 형식으로 입력해. 수식에서는 ^, sin(), cos(), sqrt(), pi 등을 사용할 수 있어.

2. 변환 행렬

입력 순서가 A1, A2, A3이면 실제 적용은 A3 * A2 * A1 * v야.
예: [0,-1,0;1,0,0;0,0,1], Rz(pi/2), A2^T, transpose(A2), A1*A2

3. 실행

LaTeX 기본 문법
x^2 → 위첨자
x_1 → 아래첨자
\frac{a}{b} → 분수
\sqrt{x} → 제곱근
\begin{pmatrix} a & b \\ c & d \end{pmatrix} → 행렬
\pi → pi
프로그램 입력창에서는 특수기호를 직접 입력할 필요가 없어.
예를 들어 Rz(pi/2), A2^T, [1,0,0;0,1,0;0,0,1]처럼 입력하면 돼.
