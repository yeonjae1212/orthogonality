Orthogonal Transformation Lab

2D / 3D 벡터·곡선·평면을 행렬로 변환하고, 직교행렬의 성질을 실험하는 도구

1. 변환 대상

입력은 키보드 문자만 사용하세요. 예: x=t, y=t^2, z=0, 범위는 t=-2..2.

2. 변환 행렬

입력 순서가 A1, A2, A3이면 실제 적용은 A3 * A2 * A1 * v 입니다.

3. 실행

변환식은 일반적인 키보드 입력으로 작성할 수 있습니다. LaTeX 모양으로 표시되는 행렬은 결과 확인용입니다.
LaTeX 기본 문법
x^2 → 위첨자: \(x^2\)
x_1 → 아래첨자: \(x_1\)
\frac{a}{b} → 분수: \(a/b\)
\sqrt{x} → 제곱근: \(\sqrt{x}\)
\begin{pmatrix} a & b \\ c & d \end{pmatrix} → 행렬
\pi → pi, \theta → theta
중요: 프로그램 입력창에서는 LaTeX의 특수기호를 직접 입력하지 않아도 됩니다. 예를 들어 Rz(pi/2), A2^T, [1,0,0;0,1,0;0,0,1]처럼 키보드 문자로 입력하세요.
