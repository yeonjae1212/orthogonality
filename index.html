Orthogonal Transformation Lab

외부 라이브러리 없이 HTML + CSS + JavaScript만으로 동작하는 2D / 3D 직교변환 실험 도구

1. 변환 대상

범위는 -2..2. 수식은 ^, sin(), cos(), sqrt(), pi 등을 사용할 수 있어.

2. 변환 행렬

입력 순서가 A1, A2, A3이면 적용 순서는 A3 * A2 * A1 * v.
행렬: [1,0;0,1]
3D 회전: Rx(pi/2), Ry(pi/2), Rz(pi/2)
참조/전치: A1, A2^T, transpose(A2)
